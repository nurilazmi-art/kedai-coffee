# Kedai Coffee

Website statis single-page untuk coffee shop fiktif **Kedai Coffee**, dibuat sebagai
tugas akhir mini project Catalyst (kategori Bisnis / Coffee Shop).

## Tujuan
Memperkenalkan Kedai Coffee, menampilkan menu, menjelaskan keunggulan kedai,
dan menyediakan informasi kontak. Target pengguna: mahasiswa, anak muda, pekerja,
dan pencinta kopi.

## Section & Fitur
- **Home**: headline, deskripsi, gambar utama, tombol "Lihat Menu" dan "Tentang Kami"
- **Tentang Kami**: cerita kedai, visi & misi, keunggulan
- **Menu**: 6 kartu produk (gambar, nama, deskripsi, harga contoh) dengan efek hover
- **Kontak & Footer**: alamat, telepon, jam operasional, media sosial, tombol WhatsApp
  (aktif setelah nomor diisi di `script.js`), tahun otomatis di footer
- Navbar responsif, smooth scrolling, tampilan responsif (desktop, tablet, smartphone)

## Teknologi
HTML5, CSS3, JavaScript vanilla. Tanpa framework, backend, atau database.

## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Buka file `index.html` di browser (atau gunakan Live Server di VS Code).
3. Koneksi internet dibutuhkan untuk memuat font dan gambar.
